# Lock Screen — Power Button Shortcut

Тап по иконке = выключить экран как кнопкой питания (Android 16, `targetSdk 36`).
Разблокировка отпечатком/лицом работает — сильная аутентификация (графключ) не требуется.

**Как устроено:** гашение через Accessibility-действие `GLOBAL_ACTION_LOCK_SCREEN`
(API 28+, `minSdk 28`). В отличие от `DevicePolicyManager.lockNow()` оно
не инвалидирует биометрию — это задокументированное поведение Android:
после `lockNow()` система всегда требует PIN/графключ/пароль.
Device Admin оставлен в приложении только как запасной путь.

**Как пользоваться:**
1. Установи APK, открой приложение первый раз → «Включить доступ» → в системных
   настройках включи Lock Screen (Спец. возможности).
2. Со второго запуска тап по иконке сразу гасит экран — бесшовно, без вспышки.
3. Долгое нажатие на иконку → «Lock» (заблокировать) / «Настройки».
4. Старые права администратора (если выдавал) можно снять кнопкой в настройках —
   для удаления приложения это тоже обязательно.

**Сборка в GitHub Actions:** пуш в `main` → `Build Debug APK` → скачай APK из Artifacts (`lockscreen-debug-apk`). Подпись debug — для личной установки достаточно.
