# Lock Screen — Power Button Shortcut

Тап по иконке = выключить экран как кнопкой питания (Android 16, `targetSdk 36`).

**Как пользоваться:**
1. Установи APK, открой приложение первый раз → выдай права администратора.
2. Со второго запуска тап по иконке сразу гасит экран.
3. Долгое нажатие на иконку → «Lock» (заблокировать) / «Настройки» (экран настроек, создание ярлыка на рабочий стол).
4. Удаление: сначала сними права администратора (Настройки Android → Безопасность → Администраторы устройства), потом удали приложение.

**Техника:** `DevicePolicyManager.lockNow()`, `minSdk 28`, `compileSdk/targetSdk 36`, иконки `mipmap-*` из `icons.png`.

**Сборка в GitHub Actions:** пуш в `main` → `Build Debug APK` → скачай APK из Artifacts (`lockscreen-debug-apk`). Подпись debug — для личной установки достаточно.
